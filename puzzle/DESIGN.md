# Rune Drift — 게임 디자인 문서

퍼즐앤드래곤 계열의 **"룬 자유 이동 + 콤보 배틀"** 퍼즐 RPG. 기존 레포(Gecko Sprint)와 독립된 `puzzle/` 패키지.

## 1. 핵심 루프
1. 6×5 보드에서 룬 하나를 잡는다.
2. 손을 떼기 전까지 보드 위를 자유롭게 끌고 다닌다(대각선 포함). 지나가는 칸의 룬과 자리가 바뀐다.
3. 첫 교환 순간부터 **5초** 제한. 시간이 끝나거나 손을 떼면 턴 종료.
4. 같은 색 3개 이상 일직선 → 제거. 빈칸은 위에서 떨어지는 룬으로 채워지고, 새로 생긴 매치도 콤보에 포함(연쇄).
5. 제거한 색에 맞는 영웅이 공격, 하트 룬은 회복. 적 카운트다운이 0이면 적이 반격.
6. 5층의 적(마지막은 보스)을 모두 쓰러뜨리면 승리, HP 0이면 패배.

## 2. 룬 (6종)
| 룬 | 역할 |
|---|---|
| 불 / 물 / 나무 / 빛 / 어둠 | 해당 속성 영웅 공격 |
| 하트 | 파티 HP 회복 |

## 3. 콤보 규칙
- 가로/세로 3개 이상 연속 = 매치. 서로 맞닿은 같은 색 매치는 **하나의 콤보**로 합산(L자, 십자 등).
- 콤보 위력: 3개 = 1.0, 1개 추가마다 +25%.
- 콤보 배율: 전체 콤보 수 × 25% 가산 (`1 + (콤보-1)×0.25`). 5콤보 = 2배.
- **가로 한 줄(6개)** 완성: 해당 속성 공격 +20%.

## 4. 오리지널 규칙 (차별점)
| 규칙 | 내용 |
|---|---|
| **서지(Surge)** | 5개 이상 콤보는 가장 아래 칸에 **강화 룬(+)** 1개를 남긴다. 다음 턴 재료로 쓰는 "투자형" 플레이 유도. |
| **강화 룬** | 콤보에 포함된 강화 룬 1개당 해당 콤보 위력 +15%. |
| **템포(Tempo)** | 한 턴 6콤보 이상이면 모든 스킬 쿨다운 추가 1 감소. 고콤보 = 스킬 회전. |

## 5. 전투
- 데미지 = `영웅 공격력 × Σ콤보 위력 × 콤보 배율 × 가로줄 보너스 × 상성`
- 상성: 불 > 나무 > 물 > 불 (2배 / 역상성 0.5배), 빛 ↔ 어둠 (서로 2배)
- 회복 = `파티 회복력 합 × Σ하트 콤보 위력 × 콤보 배율`
- 적: HP, 공격력, 공격 주기(턴). 콤보가 없어도 룬을 움직였으면 턴 소모.

## 6. 파티 (5인, 액티브 스킬)
| 영웅 | 속성 | 스킬 | 쿨다운 |
|---|---|---|---|
| 이그니스 | 불 | 나무 룬 → 불 룬 | 6 |
| 마리나 | 물 | 불 룬 → 물 룬 | 6 |
| 실바 | 나무 | 최대 HP 40% 회복 | 8 |
| 루멘 | 빛 | 모든 빛 룬 강화 | 7 |
| 녹스 | 어둠 | 적 공격 턴 +2 | 8 |

초상화를 탭해 발동(준비 시 금색 테두리). 미준비 상태로 탭하면 설명 표시.

| 층 | 적 | 속성 | HP | 공격 | 주기 |
|---|---|---|---|---|---|
| 1 | 불씨 슬라임 | 불 | 2,500 | 180 | 2 |
| 2 | 이끼 골렘 | 나무 | 4,500 | 260 | 2 |
| 3 | 심해 해파리 | 물 | 6,500 | 320 | 2 |
| 4 | 그림자 기사 | 어둠 | 9,000 | 450 | 3 |

## 8. 확장 아이디어
- 방해 룬(독/잠금), 적 선제 스킬, 리더 스킬, 영웅 수집·강화, 스테이지 맵.

## 실행
```bash
cd puzzle
pnpm run dev    # http://localhost:5174
pnpm test       # 보드/전투 로직 테스트
```

## 코드 구조
- `src/board.ts` — 보드 생성, 매치/콤보 판정, 서지, 낙하 (순수 로직)
- `src/battle.ts` — 데미지/회복 공식, 스킬, 파티·적 데이터
- `src/main.ts` — Canvas 렌더링, 포인터 드래그 입력, 턴 상태 머신
