# Rune Knight — 게임 디자인 문서

퍼즐앤드래곤 방식의 **자유 이동 룬 퍼즐**로, 화면 위에서 **혼자 전진하는 기사를 지원**하는 퍼즐 RPG.
기존 레포(Gecko Sprint)와 독립된 `puzzle/` 패키지.

## 1. 콘셉트
- **상단(전장):** 기사가 오른쪽으로 계속 걸어가며 몬스터를 만난다. 몬스터를 쓰러뜨리면 다시 전진 → 다음 몬스터.
- **하단(퍼즐):** 플레이어는 기사의 지원자. 룬을 맞춘 조합이 그대로 기사의 **행동**이 된다.
- 목표: 기사가 쓰러지기 전까지 최대한 멀리, 많이 처치(무한 진행, 최고 기록 저장).

## 2. 핵심 루프
1. 기사 전진 → 몬스터 등장(이동 중 퍼즐 잠김).
2. 6×5 보드에서 룬 하나를 잡고 **5초** 동안 자유 이동(대각선 포함). 지나간 칸과 자리 교환.
3. 같은 룬 3개 이상 일직선 → 제거, 낙하 연쇄까지 콤보로 누적.
4. 제거된 **콤보 순서대로** 기사가 행동(베기, 마법, 회복, 방어, 기력 충전).
5. 몬스터 카운트다운 0 → 몬스터 공격. 기사 HP 0 → 게임 오버.

## 3. 룬 = 기사 지원 역할 (5종)
| 룬 | 기사 행동 | 수치 |
|---|---|---|
| 검 (빨강) | 물리 베기 | 공격력 × 위력 × 체질 배율 |
| 마법 (보라) | 마법탄 | 마력 × 위력 × 체질 배율 |
| 힐 (분홍) | HP 회복 | 회복력 × 위력 |
| 방패 (청록) | 보호막 | 방어력 × 위력. **다음 몬스터 공격 1회**를 흡수하고 사라짐 |
| 기력 (노랑) | 필살 게이지 충전 | 콤보당 20 × 크기(콤보 배율 없음). 100이면 필살기(공격력×10, 저항 무시) |

- 위력 = 콤보 크기 보정(3개=1.0, +1개당 +25%) × 강화 룬 보정 × **콤보 배율**(`1 + (콤보-1)×0.25`)
- 5개 이상 콤보는 "강타", 가로 한 줄(6개)은 "관통"(+20%).

## 4. 판단을 만드는 장치 — "딜이냐, 생존이냐"
| 장치 | 설명 |
|---|---|
| **공격 예고** | 몬스터 머리 위에 `공격 260 · 2턴 후` 표시. 3번째 공격마다 **강공격(×1.8)** 을 미리 예고. |
| **예상 피해 표시** | 기사 HP 바에서 다음 공격으로 깎일 구간이 붉게 깜박인다(보호막 반영). |
| **치명타 경고** | 예상 피해 ≥ HP + 보호막이면 경고 문구. 큰 공격 콤보가 보여도 힐/방패를 택하도록 유도. |
| **공짜 회복 없음** | 레벨업·전진 중 회복이 없다. 기사를 살리는 건 힐·방패 룬과 지원 마법뿐. |
| **용의 체질** | 야생룡(약점 없음) / 철갑룡(물리 0.5, 마법 1.5) / 영룡(물리 1.5, 마법 0.5). 검과 마법 중 무엇을 맞출지 결정. |

## 5. 조합 보너스
| 규칙 | 내용 |
|---|---|
| **조화 (Harmony)** | 한 턴에 4종 이상 룬을 맞추면 모든 효과 +20%. 종합 지원을 보상. |
| **서지 (Surge)** | 5개 이상 콤보는 가장 아래 칸에 강화 룬(+)을 남긴다. 강화 룬 1개당 해당 콤보 위력 +15%. |
| **템포 (Tempo)** | 한 턴 6콤보 이상이면 모든 지원 마법 쿨다운 추가 1 감소. |

## 6. 지원 마법 (플레이어 액티브)
| 마법 | 효과 | 쿨다운 |
|---|---|---|
| 검기 각인 | 모든 검 룬 강화 | 7 |
| 마력 전환 | 검 룬 → 마법 룬 (철갑룡 대응) | 6 |
| 생명 전환 | 방패 룬 → 힐 룬 (위기 탈출) | 7 |
| 수호 결계 | 즉시 보호막(최대 HP 50%) | 8 |
| 시간 왜곡 | 몬스터 공격 +2턴 | 9 |

슬롯을 탭해 발동(준비되면 금색 테두리). 준비 전 탭하면 설명 표시.

## 7. 기사 성장 & 몬스터
- 기사 시작: HP 1500, 공격 150, 마력 140, 회복 170, 방어 200.
- 처치 시 레벨업: 공격·마력 +7%, 방어 +6%, 회복 +5%, 최대 HP +60.
- 몬스터: n번째마다 HP ×1.22ⁿ, 공격 ×1.13ⁿ → 뒤로 갈수록 몬스터 공격력이 기사 성장보다 빨리 올라 생존 판단이 중요해진다.
- 5번째마다 보스(HP ×2.2, 공격 ×1.3, 공격 주기 2턴).

몬스터는 **용이 중심**이고, 사이사이에 다른 몬스터를 만난다. 한 사이클(5마리): **용 → 기타 → 용 → 기타 → 보스 용**.

용은 관절 리그로 움직인다: 목·꼬리는 마디마다 물결치고, 날개는 관절을 접었다 펴며 펄럭이고, 다리는 발을 땅에 고정한 채 무릎이 굽는다(IK). 공격 시 몸을 젖혔다가 앞발을 내딛고 목을 뻗어 물며 브레스를 뿜는다. 쓰러질 때 다리가 접히고 목·꼬리가 늘어지며 날개를 접는다.

| 용 | 체질 | 외형 / 브레스 |
|---|---|---|
| 붉은 와이번, 화염 드레이크 / 보스 고룡 바하르 | 야생룡 | 붉은 비늘 / 화염 |
| 강철비늘 드레이크, 바위등 용 / 보스 흑철 고룡 | 철갑룡 | 강철 비늘·등판 / 서리 |
| 유령 비룡, 별빛 영룡 / 보스 심연의 망령룡 | 영룡 | 반투명 발광·공중 부유 / 마력 |

보스는 몸집이 크고 금색 뿔과 왕관 가시가 붙는다.

용이 아닌 몬스터 (모두 관절 리그):

| 몬스터 | 체질 | 관절 | 평소 / 공격 / 쓰러짐 |
|---|---|---|---|
| 굶주린 다이어울프, 피송곳니 늑대 | 야생 | 목 2마디·꼬리 5마디·다리 4개 IK·턱 | 헐떡이며 꼬리 흔들기 / 웅크렸다 도약해 물기(발톱 자국) / 주저앉음 |
| 바위 골렘, 강철 골렘 | 갑옷 | 고관절·무릎 IK, 어깨·팔꿈치·주먹 | 룬 코어가 맥동 / 두 주먹을 치켜들었다 내리찍기(땅 충격파) / 앞으로 무너짐 |
| 울부짖는 망령, 심연의 유령 | 영체 | 로브 6마디, 어깨·팔꿈치·손목, 뼈 손가락 3개×2마디 | 로브가 나부끼고 손가락이 꿈틀 / 팔을 치켜들었다 돌진하며 영혼 발톱 발사 / 위로 흩어짐 |

체질 규칙(물리/마법 배율)은 외형과 무관하게 야생=약점 없음, 갑옷=물리↓ 마법↑, 영체=물리↑ 마법↓로 동일하다.

기사도 관절 리그로 걷기(팔다리 교차), 베기(치켜들기→내려베기+내딛기), 마법(검 끝 겨누기), 방패(방패 앞으로+웅크림), 버프(검·팔 들기), 피격(뒤로 젖힘), 필살(점프 내려베기), 쓰러짐 동작을 한다. 피해는 동작의 타격 프레임에 맞춰 들어간다.

| 일반 | 체질 | 보스 | 체질 | 외형 / 브레스 |
|---|---|---|---|---|
| 붉은 와이번, 화염 드레이크 | 야생룡 | 고룡 바하르 | 야생룡 | 붉은 비늘 / 화염 |
| 강철비늘 드레이크, 바위등 용 | 철갑룡 | 흑철 고룡 | 철갑룡 | 강철 비늘·등판 / 서리 |
| 유령 비룡, 별빛 영룡 | 영룡 | 심연의 망령룡 | 영룡 | 반투명 발광·공중 부유 / 마력 |

보스는 몸집이 크고 금색 뿔과 왕관 가시가 붙는다.

## 8. 확장 아이디어
- 방해 룬(독/잠금), 몬스터 특수 패턴(룬 변환, 보호막 파괴), 기사 장비·스킬 트리, 동료 NPC, 스테이지 테마.

## 실행
```bash
cd puzzle
pnpm run dev    # http://localhost:5174
pnpm test       # 보드/전투 로직 테스트
```

테스트용 URL 파라미터: `?stage=N` (N번째 몬스터부터 시작), `?monster=wolf|golem|wraith|dragon` (몬스터 종류 고정)

## 코드 구조
- `src/board.ts` — 보드 생성, 매치/콤보 판정, 서지, 낙하 (순수 로직)
- `src/battle.ts` — 룬→기사 행동 변환, 체질/예고/보호막, 지원 마법, 몬스터 생성
- `src/anim.ts` — 관절 애니메이션 공용: 키프레임 보간, 2본 IK
- `src/knight.ts` — 기사 관절 리그 (골반·몸통·머리·어깨·팔꿈치·손목·고관절·무릎). 걷기/베기/시전/방어/버프/피격/필살/쓰러짐 동작, 발 자동 접지
- `src/dragon.ts` — 용 관절 리그 (목 5마디·꼬리 8마디·날개 어깨/팔꿈치/손목+손가락뼈 3·다리 4개 IK). 숨쉬기/물기 돌진/피격/쓰러짐 동작
- `src/monsters.ts` — 용 외 몬스터 관절 리그 (다이어울프·골렘·망령)
- `src/main.ts` — 횡스크롤 전장·퍼즐 Canvas 렌더링, 드래그 입력, 턴 상태 머신
